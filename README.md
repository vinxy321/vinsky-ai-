# 🎨 AI Image Generator

A modern and responsive **AI Image Generator** built using **HTML5, CSS3, and JavaScript**. The application generates AI-powered images from text prompts using the **Pollinations AI public image endpoint**, making it possible to create images without requiring any API key or backend.

## 🚀 Live Demo

🌐 https://salman-khanx.github.io/AI-Image-Generator/

---

## ✨ Features

- 🎨 Generate AI images from text prompts
- 🖼️ Generate 1, 2, or 4 images
- 📐 Aspect Ratio Selection
- ⏳ Loading Animation
- 🔍 Full Screen Image Preview
- 📱 Fully Responsive Design
- 🎭 Modern Glassmorphism UI
- ⚡ Fast Image Generation
- 🆓 No API Key Required

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Font Awesome
- Google Fonts (Poppins)

---

## 🤖 AI Integration

This project does **not** use Google AI, OpenAI, or any paid AI service.

Instead, it uses the **Pollinations AI public image endpoint** to generate AI images directly from user prompts. This allows the application to work without managing API keys or building a backend for this project.
